# Store assets

Store-ready images for the Chrome Web Store and Microsoft Edge Add-ons.

- `lucky-wheel-small-promo-440x280.png`: small promotional tile.
- `lucky-wheel-large-promo-1400x560.png`: large promotional tile.
- `lucky-wheel-screenshot-01-1280x800.png` through `04`: product screenshots.

All PNG files in this directory use RGB color without an alpha channel. High-resolution source images can be kept locally under the ignored `store-assets/source/` directory.
