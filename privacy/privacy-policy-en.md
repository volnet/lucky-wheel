# Lucky Draw Wheel Privacy Policy

Last updated: July 31, 2026

Lucky Draw Wheel is a fully offline browser extension.

## Data handling

- The extension does not collect, upload, sell, or share user data.
- Candidate names, display-only names, event titles, proposals, and interface settings are stored only in the extension's local browser storage.
- The extension does not read browsing history, web page content, cookies, account information, or clipboard contents.
- The extension contains no analytics, advertising, or remotely hosted code.

## Permission

The extension requests only the `storage` permission to save wheel settings entered by the user.

## Data deletion

Users can remove saved settings with the extension's reset action or clear all extension data by uninstalling the extension.

## Draw eligibility

The extension supports display-only participants. They appear on the wheel but are excluded from random selection. This is intended for guests, hosts, or other visible positions that are not eligible for a draw. Organizers should disclose the applicable draw rules to participants.
